# Mindful Parenting Project

## About the Project
This project was created during a hackathon by Marcella Wasserman and Ronny. The goal of the project is to provide a web platform to support mindful parenting practices. Built using **Node.js**, **PostgreSQL**, and **EJS**, the application focuses on user engagement, dynamic content rendering, and robust database integration.

## Features
- Dynamic content rendering with **EJS** templates.
- Database management and queries using **PostgreSQL**.
- Backend development powered by **Node.js**.

## Technologies Used
- **Frontend**: EJS templates for dynamic rendering.
- **Backend**: Node.js for server-side logic.
- **Database**: PostgreSQL for data storage and management.

## How to Run the Project

### Prerequisites
Ensure you have the following installed:
- Node.js
- PostgreSQL

### Steps
1. Clone the repository:
   ```bash
   git clone [repository-link]
   ```
2. Navigate to the project directory:
   ```bash
   cd mindful-parenting
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Set up the database:
   - Create a PostgreSQL database.
   - Run the provided SQL scripts (if applicable) to set up tables.
   - Update the database connection details in the `.env` file.
5. Start the server:
   ```bash
   npm start
   ```
6. Access the application in your browser at `http://localhost:3000`.
